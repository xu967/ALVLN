# T5 大规模采集（600 集）

- 时间：2026-10-30 11:32 起（pilot），11:55 起（全量）
- 范围：`sim/tools/collect_parallel.py`（4 实例、40 步、safe 出生 20%）
- 数据：`$DATA_ROOT/uav_rgb/t5-pilot-1132`（52 集）、`t5-full-1155`（599 集，隔离 1 集）
- 状态：**完成**（2026-10-30 16:19 采集结束，17:00 过闸门）

## 1. 并行上限

T2 实测 4 实例 = 1.95 步/s；8 实例会把 RTF 打到 0.1、起飞超时。本轮另有
其它会话（`/root/cls` 的 benchmark）抢 CPU，4 实例实测 1.67 步/s。因此全量
仍用 **4 实例**，不放大。

## 2. Pilot（52 集，base-seed 100000）

```bash
DISPLAY=:20 XDG_RUNTIME_DIR=/tmp/xdg "$UAV_RGB_PYTHON" sim/tools/collect_parallel.py \
  --instances 4 --episodes-per-instance 13 --steps 40 --hold 1.0 \
  --base-seed 100000 --policy teacher --spawn-mode default --safe-spawn-fraction 0.2 \
  --out "$DATA_ROOT/uav_rgb/t5-pilot-1132"
```

| 项 | 结果 |
| --- | --- |
| 成功集数 / 步数 | 52/52，2080/2080 |
| 墙钟 | world_gen 2.9 s + collect 1248.7 s = 1251.6 s（20.9 min） |
| 吞吐 | 1.666 步/s；约 150 集/h |
| 失败/碰撞 | 0 集失败、0 碰撞步 |
| split | train 40 / val 5 / test 7 集（gid 39/4/7） |

audit（`--exclude-collision-episodes`）：10/11 PASS，唯一 FAIL 是
`class_share: val:SAFE_NEUTRAL` 缺席——safe 出生按列表位置每 5 集铺 1 个，
pilot 的 5 个 val 集恰好都没踩中；不是标签错误（`label_recompute 0/2080`）。
全量 600 集 val 约 60 集，预期 SAFE 约 12 集，不会缺。

## 3. 全量（600 集，base-seed 200000）

## 4. 结果

| 项 | 结果 |
| --- | --- |
| 集数 / 步数 | 600/600 集，24000/24000 步（11 集首发丢指令，重试 1 次全部救回） |
| 墙钟 | world_gen 37.4 s + collect 15932.8 s = **15970.4 s（4 h 26 min）** |
| 吞吐 | **1.506 步/s**，约 135 集/h（pilot 150 集/h；本机另有会话抢 CPU） |
| sim_dt | mean 1.001 s，min 1.000 / max 1.020，cv **0.3%** |
| 观测同步 | depth/pose 与 RGB 最大 gap 36.0 ms（阈值 50 ms），超限 0 步 |
| 碰撞 | 1 集 9 步 contact（`test/200207`，13:22 日志里那组）；无 stuck 步 |
| 类别分布 | train 18520：SAFE 3760 / FWD 11446 / LEFT 1577 / RIGHT 1737；val 2800：600/1715/263/222；test 2640：440/1714/213/273 |
| audit | **11/11 PASS**（599 集 / 23960 步，`t5-full-1155/audit.json`）；`label_recompute` 0/23960 不一致 |
| 打包 | 599 集 → 23960 步 / 1.38 GB / 46.0 s（`t6-full-1640/ds/dataset.uavr`） |

两处失败与处置（详见 `worklog/2026-10-30-1650-t5-audit-fixes.md`）：

- `yaw_direction` 3 个异常步全是「反向偏航接续步」：上一步反向 YAW 的角速度
  要先被抵消，净 dyaw 不可测。检查跳过反转步并计数，`YAW_MIN_DEG=0.5` 不动。
- `safe_collision`：`test/200207` 接触后教师连续 7 步输出 SAFE，整集隔离到
  `$DATA_ROOT/uav_rgb/t5-full-1155-quarantine/`；audit 按 599 集 PASS。

结论：T5 配方（4 实例 × 40 步、hold=1.0、safe 出生 20%）可复现，吞吐 1.5 步/s
是当前机器的上限（RTF 受 CPU 共享影响）；数据可用于 T6。

用 pilot 的 52 集走完整 T6 命令，提前暴露集成问题。目录
`$DATA_ROOT/uav_rgb/t5-pilot-dryrun-1325/`。

| 项 | 结果 |
| --- | --- |
| preprocess（新 split 门禁） | 52 集 / 2080 步 / 119.8 MB，6.2 s |
| 训练（10 轮，batch 64，`--class-weights auto --drop-collision`） | 1600 train 样本 ×10 轮 = 16000，496.5 s，**32.2 样本/秒**（采集中并行，CPU 被抢；T3 空载 52.9） |
| eval-only `ckpt_best.bin --split all` | val n=200：acc 0.8200 / macro_f1 0.4458 / bal_acc 0.4024；test n=280：acc 0.8607 / macro_f1 **0.6400** / bal_acc 0.6073 |

- 链路通：新 preprocess 门禁、`--drop-collision`、eval-only best、baseline 过滤都按预期工作。
- 口径提醒：pilot 的 val 没有 SAFE（audit FAIL 已解释），val recall SAFE=0；test 的
  SAFE recall=1.0 只来自 2 个悬停集（support 80），不能当「学会避障」的证据。
- 排期：全量 24000 样本 ×10 轮，按空载 ~53 样本/秒 ≈ **75 min**（采集并行时 ≈2 h）。
