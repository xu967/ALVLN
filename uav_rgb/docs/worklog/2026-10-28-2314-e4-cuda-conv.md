## 风险与遗留

- CUDA 包装每次调用同步 + 临时分配（parity 专用），训练时吞吐会低一个数量级，E5 前要改持久缓冲。
- 2080 Ti 无 ECC，float 累加项多时（大 batch/大核）dW 误差会缓慢增长，1e-4 门槛目前余量 ~6.5 倍。
- gradcheck 用 loss=Σy²（二次型，中心差分无截断误差），比真实 CE 训练目标更严苛也更干净，
  但与 doc 04 N2（与 NumPy/PyTorch 测试级 oracle 对拍）无关——本项目禁装 PyTorch，N2 未做。
- softmax loss 的 double atomicAdd 归约顺序不确定（可复现性在 double 精度下可忽略，实测 loss 差为 0）。
