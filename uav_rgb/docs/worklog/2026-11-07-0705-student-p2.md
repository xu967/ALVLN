## 做了什么

### 数据格式（偏离任务原话「UAVR 版本升一位」，改为侧车；理由见 DESIGN §1 / DATASET_FORMAT §5）
- 新增 **UAVRAUX1 侧车 `dataset.aux`**（`tools/DATASET_FORMAT.md` §6）：128 B 头（N、flags、深度网格、K=8、
  unknown=255、`dataset.uavr` 整文件 SHA256、payload SHA256、7 个分带上界、包络半径）+ `u32 prev_index[N]`
  + `u8 prev_action[N]` + 可选 `u8 depth[N·15·20]`。`dataset.uavr` 字节不变；meta 追加 `aux_sidecar` 摘要。
  不升版本的原因：`tools/join_soft_targets.py`（TEACHER-P1 域，按 UAVR SHA 绑定软标签）、
  `tools/baseline_priors.py`、`tools/train_student_with_video.py` 都写死 `version==1`。
- `tools/preprocess.py`：`load_episode` 逐样本带 `prev_action`（上一步 `action_executed`，旧数据退回
  `action_expert`；首帧 SAFE）与 `depth_file`（manifest `depth_format` 决定加载器：`png16_mm` / `npy_float32_m`）；
  新函数 `cell_min_depth`（每格最小有效深度）、`dilate_by_envelope`（像素半径 f·r_env/z，f = manifest fx 或 60° HFOV）、
  `depth_bands`、`aux_payload`、`write_aux_sidecar`（tmp+rename）；`--envelope-radius`（默认 0.102 m，
  e1_mini.json）。上一步被 `--drop-collision` 丢掉时 prev_index 指向自身（同首帧）。一包深度要么全有要么全无。
  写前删旧 `dataset.aux`，避免「新 uavr + 旧侧车」。
- `tools/read_dataset.cpp`：有侧车时校验头/长度/两个 SHA256（自带最小 SHA-256，仍不链接库）/取值范围；
  `--selfcheck` 核对合成集 prev 链（首帧 0/6/10 指向自身、prev=SAFE，其余 prev = 上一步标签）。
- `src/aux_sidecar.{hpp,cpp}`（新）：`load_aux_sidecar` 全量校验（N/H/W、flags、SHA 绑定、范围），
  不存在 → `present=false`；`dataset.cpp` 末尾挂到 `UavrDataset::aux`。
- `src/tests/synthetic_dataset.hpp`：`SynthDataset.labels` 暴露标签；新 `write_synthetic_aux`
  （prev 链 + 深度目标 = 样本标签、`(i+r*3+c)%7==0` 格置 255）。

### 模型 / 算子
- `make_cnn(..., in_c=3, aux_classes=0, prev_dim=0)`；FiLM 条件向量 `[text_feat | onehot(prev)]`
  （`cond_dim`/`has_film` 辅助函数）；辅助头 `Conv2d(64, 8, 1)` 接在 FiLM 之后的第三层特征；
  `aux_forward` / `backward(..., daux)`。参数顺序：8 基础 → text_emb → film.W/b → aux.W/b（旧 v4/v5 不变）。
- 新算子逐格 softmax-CE：`ops_spatial.cpp`（CPU 参考 + FP64 gradcheck）、`spatial_ce_cuda.cu`
  （kernel、`dev::spatial_ce`、`dev::add_inplace`、host 包装）；255 屏蔽、按有效格数归一、全屏蔽 loss=0/grad=0。
- `DeviceCnn`：`forward(..., prev)`、`aux_loss(targets, λ)`（只有调它才算辅助头 → 推理不花 MAC）、
  `aux_backward` 把 λ·dL/d(aux logits) 经 1x1 反卷积叠进 fc 的 dx，本步没目标则辅助头梯度清 0。
  拆文件守行数预算：`model_dev_aux.cu`（辅助头）、`model_dev_film.cu`（FiLM 条件分支，纯搬移）。
- checkpoint v6：v5 契约之后追加 `i32 aux_classes`、`i32 prev_dim`；v2..v5 照读（字段为 0）。
  `read_checkpoint_meta` 返回 `aux_classes/prev_dim`。

### 训练器 / 推理
- `uavrgb_train`：`--two-frame`、`--prev-action`、`--depth-aux`、`--aux-lambda`（默认 0.5）；缺侧车/缺深度
  直接报错（不静默降级）；写进 `config.json`，resume 继承，`--eval-only` 结构以 checkpoint 为准。
  双帧的上一帧按 `prev_index` 现读（文件里图像仍 3 通道）；flip 增强时 prev-action L/R 互换、深度目标按列镜像；
  shift 不动深度目标（`shortcut:` 注释）。stdout/metrics 每轮追加 `depth_ce/depth_acc`（train/dev），
  `--eval-only` 也打；`results.csv` 口径不变（loss 仍是动作 CE）。
- `uavrgb_infer`：hello 加 `prev_action_dim`、`aux_classes`；一步 = `in_c/3` 张 HWC 帧（当前、上一）+
  1 字节 prev-action；通道 0..2 当前帧、3..5 上一帧；越界/截断报错。
- `sim/tools/student.py`：接受 in_c 3/6、`prev_action_dim` 0/4；帧缓存与上一步动作放 Python 侧
  （推理进程无状态、集边界只有采集脚本知道）：`reset()` 换集、`act(msg, prev_action=None)` 可传真正执行的动作。
  类级默认值保证 `tools/check_input_parity.py` 的 `__new__` 路径仍只发 h·w·3 字节。
