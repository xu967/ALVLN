## 风险与遗留

1. `dataset.cpp` 仍是最小字符串扫描器，未完整验证 JSON 结构、重复键、转义、嵌套对象等；本次防止正常格式中的场景/区间泄漏，不等于已具备任意外部不可信文件解析能力。
2. `Tensor::numel()` 缺少乘法溢出校验；部分 NN CUDA 入口对空张量/极大维度检查不足。当前模型固定尺寸和测试不触发这些路径。
3. `nn_cuda.cu` 的 CUDA 错误仍 `exit`，与 Linear/Conv/Softmax 的异常方式不统一；无法统一保证失败事件落盘。
4. 部分 gradcheck 在独立 FP64 实现中比较，而没有直接将所有实际 FP32 backward 对接外部数值 oracle；CPU/CUDA parity 不能排除共有公式错误，不能夸称“全部算子已外部验证”。
5. 训练 CLI 未完整拒绝 NaN/Inf 学习率、梯度阈值以及带尾缀的数字；JSON 字符串转义未覆盖所有控制字符；checkpoint 读入时失败可能已部分修改目标，且权重/Adam 数值有限性检查不足。
6. 加权训练 epoch loss 仍按 batch 样本数平均已按权重和归一化的 batch loss，不等价于全 epoch 的全局加权 CE。dev_ce 本次已修为无权 CE，不受此问题影响。
7. resume 保存参数、Adam状态和epoch，但未保存随机数状态/上一轮shuffle顺序，续训不保证与不中断训练逐步完全一致。
8. 模型目前是 100388 参数 CNN 四动作分类器，没有语言模块、GRU或闭环 evaluator。旧 CLAUDE.md“没有trainer/Adam”已过时，交接的“全部完成”同样不可推导。
9. `preprocess.py` 对 step/action 用 int 强转，collision 用 bool 强转，manifest有效性没有作为训练准入门槛。不同来源数据进入前仍需做类型/真值质量审查。
