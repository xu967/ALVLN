## 没做什么 + 原因

- 没改 `gz/`、`proc/`、`selftest/`、`tests/`、`tools/check.sh`：属于其他 agent 的文件域。`sticks[4]` 追加字段需要它们各自跟进（见「待确认」）。
- FAILSAFE 没有让固件 `descend()` 接管（头文件注释如此写）：HANDOVER 第 3 项规定 FAILSAFE = 油门悬停前馈 + 水平，且执行器每 tick 都刷新 RC，固件不会判 RC 丢失。按 HANDOVER 实现，差异写进 README。
- 没做 `calibrated=true`/真机校准：全部数值 `assumed/doc/firmware`，真机四项（推力曲线、悬停占空比、质量、惯量）见 `open_items`。
- 没调低开环 xy 漂移（8 个种子 0.10–0.49 m / 15 s）：来源是固件飞行中不用加计修正的姿态漂移，速度环积分已抵消其斜率；更激进的速度环增益会振荡。
- 解锁前没有让固件校准陀螺零偏（真机会静置 2 s）：SITL 直接解锁，零偏残差 = `gyro_bias_residual` 抽样，`basis` 已注明。
