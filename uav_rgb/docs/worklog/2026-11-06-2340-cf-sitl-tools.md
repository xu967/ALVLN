## 做了什么

- `sim/cf_sitl/proc/cf_sitl_proc.cpp`（195 行）：BRIEF §4 协议进程。`--params <json> [--seed N]` 启动即 `cf_sitl_init`；每行一个 JSON 请求、一行应答、立即 flush；`reset / takeoff / act / step / state / quit` 六条命令，任何坏输入（非 JSON、空行、缺 cmd、未知 cmd、字段类型/范围错）都应答 `{"ok":false,"error":"…"}` 且进程不退出；`quit` 或 stdin EOF 退出 0。`state` 输出 `cf_sitl_state` 全部字段（含后加的 `sticks[4]`，用模板探测成员，旧头文件也能编）。进程启动后把 fd 1 改道到 stderr，应答只走 dup 出来的描述符，固件/库里任何杂散输出进不了协议流。
- `sim/cf_sitl/proc/CMakeLists.txt`：`cf_sitl_proc` 链接 target `cf_sitl`；json_min 另编一份静态库 `cf_sitl_tools_json`（库用 `-fvisibility=hidden` 不导出 Json 符号），`if(NOT TARGET)` 守护，三个子目录谁先进都行；可执行文件放构建根目录。

  - `selftest_config.h`：全部超参数（时长、注入量、阈值），每行一个、行尾写依据。

### 过程中的两次失败（run3 → run5）

- run3 按真值判：俯仰稳态 +16.24° 超 ±5% 带，松杆后真值一直停在 ~1.5°。CSV 对照估计值后确认是固件姿态估计误差（阶跃期间陀螺积分累计 +1.2°，飞行中不修正），改为按估计值判。
- run3 俯仰段后只固定等 4 s 就做偏航阶跃：此时执行器还在补高（z 2.16 m、仍在爬），悬停杆在旁路期间从 0.894 积到 0.925（高度积分看着掉高在加，输出却不送固件），偏航段油门用这个值 → 3.5 s 旁路里一路爬到 3.23 m，ToF 超 2.5 m 量程 → FAILSAFE。改为等「高度稳住」判据（8.87 s）再做偏航阶跃。
- run4 松偏航杆后 1 s 内 |r| 没回到 < 5°/s（反向回摆到 +68°/s，这是速率环积分卸载），放宽到 2 s 观察窗；这一项本来就只打印不判。

### 给 core / 执行器维护者的信息

- 旁路期间执行器积分照常累加（`hover_stick` 0.894 → 0.925，3.5 s 掉高 0.8 m）：如果以后要在旁路里做更长的实验，建议旁路时冻结执行器积分，或者调用方自己管油门。本自检已避开。
- 打杆 +0.5 俯仰 1.5 s 掉高 0.29 m、前向加到 2.74 m/s；松杆后执行器刹车要先俯仰 −10°，高度最低到 1.15 m 再回 2 m，全程 8.9 s。standalone 没地面/障碍，真机或 gz 里做这个动作要留出空间。
- 松偏航杆后反向回摆峰值 ~70°/s、1.2 s 才停：固件速率环积分在 150°/s 下攒的量；真机上这会表现为松杆后「回弹」，是否可接受由 CF-Drone 侧判断。
