## 风险与遗留

- profile 串第三次变化（bd0dcd43 → cec5d6b0 → 683e7400 → 1bc8fedf:lib31），之后只有 value 变或库版本号变才会再变；改注释/basis 不变。`CF_SITL_LIB_VERSION` 要手工递增，改 `sim/cf_sitl` 行为而忘记升号的话 profile 不会变（README 写了规则）。

- `completed` 是新字段，读旧 3DGS manifest 的工具要按 `num_steps == requested_steps or stopped_on_goal` 补算（DATASET_FORMAT §1.5 写了）。
