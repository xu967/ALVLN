# L2 文本分支（自研 C++/CUDA，D-STACK=A）

- 时间：2026-10-31 10:40–11:15
- 范围：`src/model.cpp`、`src/dataset.cpp`、`src/checkpoint.cpp`、`src/trainer*.cpp`、
  `src/infer*.cpp`、`src/train_main.cpp`、`tools/preprocess.py`、新增 `src/tests/test_text_branch.cpp`
- 结论：完成。21/21 CTest 通过，embedding 解析梯度与中心差分对拍 `max_err 9.5e-06`。

## 做了什么

- 新增 `src/include/uavrgb/text.hpp`：`kTextLen=8`、`kTextVocab=22`，与
  `sim/tools/instruction.py` 的 VOCAB 对齐（Python 是唯一 tokenize 真源）。
- 模型（`model.hpp/.cpp`）：`make_cnn(..., text_dim=0)`；`text_dim>0` 时建
  `text_emb[kTextVocab, text_dim]`，前向把 token id 查表后**忽略 `<pad>` 求均值**，
  与 flatten 特征逐样本 concat 成 `[N, flat+text_dim]` 再进 fc；反向把 fc 的 dx 拆成
  图像段与文本段，文本段按 token 累加回 embedding。
- 数据（`dataset.cpp`）：读 `dataset.uavr` 同目录的 `instructions.jsonl`，把
  `text_ids` 按 `sample_start/sample_count` 展开成 `[n, kTextLen]`；无侧车则
  `text_ids` 为空（无文本模型照常训练），需要文本却缺侧车时直接报错。
- checkpoint：版本升 **v4**，`text_dim` 只**追加**在 `best_macro_f1` 之后，
  v2/v3 偏移不变；`read_checkpoint_meta` 返回 `text_dim`，推理端据此决定要不要读 `--text`。
- 训练（`trainer.cpp` / `trainer_eval.cpp`）：`--text-dim N`；训练与评估都按 batch
  送 token id；`eval_only` 以 checkpoint 记录的 `text_dim` 为准。
- 推理（`infer.cpp`）：`--text` 现在真的进模型（补齐到 `kTextLen`）；**没有文本分支的
  checkpoint 仍然忽略 `--text`**，保持 L0 行为，image-only 权重在带指令的采集链路里照跑。
- `tools/preprocess.py`：`instructions.jsonl` 增加 `text_ids`（并检查超过 `TEXT_LEN` 报错）；
  另新增 `--exclude-safe-episodes`（按 `planner=plan_action` 整集剔除）。
- 新测试 `test_text_branch`：token 影响 logits、`<pad>` 不影响、embedding 中心差分
  对拍（含「未出现 token 梯度为 0」）、侧车展开、checkpoint v4 往返与结构不符拒绝。

## 没做什么

- **没有训练任何文本模型**：只打通了链路；L2 训练要等 image-only 闭环基线结果出来。
- ~~没有重打包数据集~~（2026-10-31 11:35 已用新 `preprocess.py --drop-collision` 重打
  `l1-full-400-0803/ds`，`instructions.jsonl` 400 行全部带 `text_ids`；image-only 权重
  复评指标逐位不变）。
- **没有做 FiLM**：先按最小方案 concat；语言增益不显著再升级。
- **没有改 `src/build`**：评测正在用 `src/build/uavrgb_infer`，本次编译都落在
  `src/build-l2`，避免替换运行中的二进制。
  - 原因：闭环评测每个 episode 都会拉起 `uavrgb_infer`，中途换二进制会让同一次评测
    前后用的不是同一个模型。
- 没有提交、没有推送。

## 风险与遗留

- 修了一个只在多卡 batch 下才暴露的错误：最初把 `[N,flat]` 和 `[N,D]` 整体 memcpy 拼接，
  N>1 时行错位（样本 0 会读到样本 1 的特征）。gradcheck 用例用 N=2 才抓到；
  单样本推理（infer）永远发现不了。
- 文本增益的统计力仍然受 test 集 34 集限制。
- `text_emb` 初始化用 Xavier；如果训练不收敛，先看文本分支是否是瓶颈（可先冻结 embedding）。
