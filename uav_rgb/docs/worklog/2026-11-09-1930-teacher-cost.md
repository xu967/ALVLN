## 做了什么

- `sim/tools/teacher.py`：
  - 抽 `_grid_spec` / `_MOVES`（`astar_path` 改用，行为逐位不变：两组 A* 路径哈希锁）；抽 `_rollout` / `_q_from`（`_q_after_yaw` 改用，`lr_tie_margin_steps` 逐位不变：8 组硬编码锁 + sgvis 10659 帧行内 `tie_margin_steps` 回归）。`TIE_*` 五个常量成为一步原语模型的唯一来源。
  - 新增 `GeodesicField`（目标出发 Dijkstra，膨胀带内 3×3 邻域回退，`descent_dir` 0.7 m 胡萝卜方向）、`geodesic_field`（按场景缓存 16 张）、`plan_costs` → `(Q[4], info)`、`plan_action_costmap` → `(action, info{q, tie, fallback})`、`TEACHER_COST_VERSION = "uavrgb.teacher_cost.v1"`。tol 与前瞻步数是显式参数。
  - 相对 q1 参考实现修了 `descent_dir` 的量化 bug（按单位长度下降率、同率先直走；细节见实验文档 §0）。
- `sim/tools/collect.py`：`--teacher-planner costmap`、`--costmap-tol`、`--costmap-lookahead-steps`；`collect_one(costmap_opts=…)` 分支调 `plan_action_costmap`，行内多 `q_costs`（`action_row` 白名单加一项，关着时字段集不变）；manifest `planner=costmap`、`teacher_version=TEACHER_COST_VERSION`、`costmap_tol_deg`、`costmap_lookahead_steps`；参数校验（只配 `--policy teacher` + `--scene-meta`；两个参数只配 costmap）。
- `sim/tools/collect_parallel.py` / `sim/tools/eval_closed_loop.py`：choices 加 `costmap`，两个参数透传（非默认才追加，默认命令行逐字不变），同样的互斥校验。
- `sim/tools/audit_dataset.py`：`label_recompute` 按 `planner=="costmap"` 选 `plan_action_costmap`（版本比 `TEACHER_COST_VERSION`，tol / 前瞻按 manifest 复算）；`episode_facts` 多读两个 manifest 字段。
- `tools/relabel_costmap.py`：离线重标到副本目录（rgb/scene/oracle 硬链接，actions 重写，manifest `relabel_from=legacy`），统计 JSON+MD（一致率 / 混淆 / 分区域 / 分 |err| / 分视锥 / 标签分布 / fallback / 平局）；`--no-copy` 只算统计。
- `tools/export_costmap_soft.py`：`q_costs` → npz `{episode_id}/{step}/logits = log softmax(−Q/α)`，带 `teacher_version` / `alpha_steps` 来源键；无 Q 的帧写硬标签峰分布并计数。
- 测试：新 `sim/tools/test_teacher_costmap.py`（44 项合成 + `--data` 回归）；`test_collect.py` +9、`test_collect_parallel.py` +1、`test_audit_dataset.py` +case 24（都先红后绿）。

## 没做什么

- 没改 `tools/e1_pipeline.py`：属 FIX-A 文件域（BRIEF §2）。流水线要跑 costmap 教师需在 `collect()` 里按 `CFG["teacher_planner"]` 追加 `--teacher-planner costmap`（3 行），写在报告里交主会话。
- `--policy student`（DAgger 影子教师）仍只用 A* 标签：三处透传只覆盖 `--policy teacher`；costmap 版 DAgger 需要 `collect_one` 影子教师分支再加 `costmap_opts`，本轮任务书没列，没做。
- `--tiebreak visible` 与 costmap 没有联动：costmap 自己的平局规则（两 YAW 平局按可见柱反侧）已内置，`teacher_tiebreak` 字段对 costmap 集无意义，manifest 仍按命令行写 `legacy`。
- 两步前瞻与 tol=0 只算了离线统计，没进闭环：tol=0 的标签 YAW 占 21% 且把 legacy 容差内的 FWD 判成转；两步前瞻平局多 13 倍（第二步取 SAFE 使 Q 并列）。预注册只排默认变体进闭环。
- 没做 3DGS 侧：`plan_costs` 只吃柱子真值；3DGS 占据栅格接法写在报告「接口」一节。
- 没复用 eval3 / eval4 的数字：eval4 到写文档时还没落地；对照臂（legacy 教师、截断臂学生）都自己同条件跑。
- 软标签闭环只跑 α=0.5（任务书规定）；hard-argmin、α=0.25、α=1.0 只有离线指标。
- 没有重训 legacy 截断臂：对照直接用 eval3 的 `ckpt_trunc_distill.bin`（= agent6 `trunc/run/ckpt_best.bin`，同配置、不同构建的训练器）。
- 没把 `descent_dir` 的修法回灌到 `agent6-distill/q1_cost_to_go.py`：那是只读探针目录。
- 带 bug 的第一次闭环 ①（两臂各 1 集成功）与训练链被按 PGID 停掉，目录留档 `*-flawed-descent-*`，数字不用。

## 风险与遗留

- `_FIELD_CACHE` 按 `json.dumps(pillars)` 做键：柱子字典里带浮点抖动的不同场景不会误命中，但同一场景在 Pool 的每个 worker 里各算一次（毫秒级，可接受）。
- costmap 的 `fallback=all_collide` 退回 `plan_action`：这些帧（0417 的 263 帧）标签不是 Q 的 argmin，软标签导出时写成硬标签峰分布；若软标签臂要「纯 Q」，应把这些帧从训练集丢掉。
- 栅格浮点格心让膨胀带左右差一格（`_point_blocked` 与 A* 同一现象）：Q_L / Q_R 在镜像位姿上不严格对称（差 < 一跳）。
- 闭环 RTF：4 个 gz + 训练同时跑时每集 8–10 min（12 核 cgroup），只剩自己 2 个 gz 时约 3 min。
