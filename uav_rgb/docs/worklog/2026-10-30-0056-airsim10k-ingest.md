# D0c：接入 Kaggle AirSim 10k 公开数据集

- 时间：2026-10-30 00:56
- 范围：`tools/airsim_to_uavr.py`（新）、`tools/preprocess.py`、`tools/check.sh`
- 结论：**完成**。数据校验、清点、离散化、打包、训练全部跑通；
  结果是「可用但不能单独用」——`SAFE_NEUTRAL` 为 0 条。

数字都在 `docs/experiments/2026-10-30-airsim10k.md`，这里只记过程与边界。

## 做了什么

- 校验下载：127/127 分块（每块 16 MiB，断点续传记在 `.done`），
  2,116,088,484 字节；解压到全新空目录，30000 个文件、序号 `000000`–`009999`
  连续、无缺口、无空文件。
- `tools/airsim_to_uavr.py`：把 `(vx, vy, vz, yaw_rate)` 离散成 4 类，
  中心裁 320×320 → 320×240 再缩到 160×120（保持 4:3），按序号连续块分
  train/val/test，调用 `preprocess.write_dataset` 写 `.uavr`。
- `tools/preprocess.py` 增 `crop` 可选参数（`load_frame` / `write_dataset`），
  默认 `None`，既有行为不变。
- `tools/check.sh` 增一行跑 `airsim_to_uavr.py --self-check`（11 项）。
- 用深度图做了标签自洽性检验：左右接近度差与转向标签差 25.8 sigma。

## 没做什么

- **没有验证势场法标签本身**。没有场景几何、没有无人机世界位姿，
  「这个转向决策是否最优」无法判定。能验的只是「标签与图像是否对得上」。
- **没有用 depth 训练**。模型输入只有 RGB；depth 只用于上面的检验。
- **没有做场景级 split**。数据没有场景/位置元数据，只按序号连续块切，
  保证不了 test 是没见过的场景。
- **没有重新标定离散化阈值**。`10 deg/s` 是拍的，没跟训练效果联动过。
- **没有跑闭环**。这份数据的世界不是我们的柱阵，闭环没有意义。
- **没有清理原始数据**。`pubdata/` 下还留着 2.0 GiB 的 zip 和 3.5 GiB 的解压目录。

## 待确认

- `10 deg/s` 判转向 vs 我们的 `YAW = 0.6 rad/s = 34.4 deg/s`，两者差 3 倍多。
  阈值取在哪个位置才算「和我们同一个动作口径」，没有依据。
- 过拟合明显（train_ce 一路降到 0.18，dev_ce 从 0.76 升到 1.70）。
  `lr=1e-3` 对 7000 样本偏大；要不要重跑一轮低 lr 的，看这份数据是否还值得投入。

## 更新 2026-10-30 02:30：评审后的修复

- `tools/preprocess.py`：`load_frame` 加 `src_expected` 参数。**这是评审 P1-1**：
  加了 `crop` 之后 `im.size != (src_w, src_h)` 变成恒真式（裁完永远是 crop 盒子
  的尺寸），100×100 或 640×640 的源图会被静默打包成黑边/错视野样本而不报错。
  现在 `src_expected=(320,320)` 在裁剪前校验原图尺寸。
- `tools/airsim_to_uavr.py`：
  - 文件名必须整名 `6 位数字.png`，且序号必须正好是 `0..n-1`。原来 `f[:6]`
    会把 7 位的 `1000000.png` 静默截成 `100000`，和别的帧配错标签。
  - `--blocks` 校验个数必须为 2、且满足 `0 < a < b < 1`（原来 `--blocks 0.7`
    抛 `IndexError`，三个值则静默忽略第三个）。
  - 指令文件形状不一致、维度不是 `(4,)` 时给 `die` 而不是 `np.stack` 的裸
    `ValueError`。
  - 新增 `--check-labels`：把「标签 vs 深度左右几何」的 25.8 sigma 检验做成
    可复跑命令（原文档里的数字没有对应脚本，评审 P3-17）。判据
    `|标准化差| < 2 sigma` 判 FAIL。
- 文档口径修正：`sim/README.md` 里「`--hold` 是 wall 秒、未实现 sim-time
  advance」已改；`docs/ENGINEERING_RULES.md` 的「采集不可复现（`--hold` 是墙钟秒）」
  一行删除（问题已不存在）。
- 实验文档补「数据集描述与实测不符」一节，并注明两个 split 边界上各有一对相邻帧
  分属不同 split（泄漏 2/10000，可忽略，但原文说「不跨块相邻」是错的）。

验证：`airsim_to_uavr --self-check` 11 项；`--check-labels` 复现 25.8 sigma；
数据集重打包 10000 样本 549 MiB；`--blocks` 三种错输入都被 `die` 拦住；
`tools/check.sh` EXIT=0。
