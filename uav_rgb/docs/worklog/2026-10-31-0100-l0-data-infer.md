# L0 指令数据通路与 infer 文本入口

- 时间：2026-10-31 00:35–01:10
- 范围：`tools/preprocess.py`、`sim/tools/audit_dataset.py`、
  `sim/tools/test_audit_dataset.py`、`tools/make_synthetic_episode.py`、
  `tools/check.sh`、`sim/tools/student.py`、`src/infer_main.cpp`、`src/infer.cpp`、
  `src/include/uavrgb/infer.hpp`、`src/tests/test_infer_io.cpp`
- 结论：完成 L0 数据侧 + 文本入口；模型尚未接文本（L2）。

## 做了什么

- `tools/preprocess.py`：读每集 `episode_manifest.json` 的 `instruction`，
  写旁路 `instructions.jsonl`（`episode_id/instruction/sample_start/sample_count`）；
  指令只覆盖部分 episode 时非零退出（`instruction 只覆盖部分 episode`）。
- `sim/tools/audit_dataset.py`：新增 `instruction_coverage`（12 项检查）：
  全有非空 → PASS；部分缺/空 → FAIL；含坐标/带单位小数 → FAIL；全无 → SKIP。
- `sim/tools/test_audit_dataset.py`：新增第 15 组用例（PASS/部分缺 FAIL/坐标 FAIL）。
- `tools/make_synthetic_episode.py` + `tools/check.sh`：合成 fixture 带 3 条指令，
  check.sh 断言 `instructions.jsonl` 存在且 3 行。
- `src/infer_main.cpp` / `infer.cpp` / `infer.hpp`：新增 `--text <id,id,...>` CSV；
  L0 只解析/校验，前向不使用 text_ids（L2 接文本编码）。
- `sim/tools/student.py`：`StudentPolicy(..., text_ids=None)`，非空时给
  `uavrgb_infer` 传 `--text`。
- `src/tests/test_infer_io.cpp`：带 text_ids 的单帧回归（L0 不应改变动作输出）。

## 没做什么

- **没有改 `collect.py` 的 instruction 字段**：T5b 采集要用它，等采集结束再改。
- **没有生成真实语言数据**：L1 的彩色柱/指令模板还没做。
- **没有把文本接进模型**：L0 只通管道，文本编码器/融合是 L2。
- **没有用多指令/TEXT 头**：`--text` 是单集一条；多指令再升协议。
- **没有在 T5b 采集期间跑 build/CTest**：按车道互斥。

## 风险与遗留

- `instructions.jsonl` 以 `episode_id` 为键；故意不支持「一集多指令」，升级点写在 L0 任务行。
- `--text` 是进程级、单集一条；多指令/多轮要改 TEXT 头协议。
- L0 的文本向量尚未参与前向，真实语言增益要等 L2 消融才能判断。
