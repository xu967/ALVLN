# 校园可信基线实施

- 时间：2026-11-03（Asia/Shanghai）
- 范围：uav_rgb 的采集、评测、数据打包、蒸馏读写、校园 pilot 与文档；根 README 入口同步。
- 结论：工程链路完成；学生小样本闭环完成但测试成功率为 0/1，以独立实验记录为准。

## 做了什么

- 两个并行 agent 分别修 contact 事件与蒸馏身份；主 agent 完成集成、校园任务和验证。
- `collect.py/gz_io.py` 跨步骤保存接触事件序号，在订阅线程锁存，覆盖缓冲淘汰/推理/漂移。
- `student.py` 统一构建入口并约束进程读写超时；修复教师策略测试的 waypoint 参数。
- `join_soft_targets.py` 与原生读端采用 UAVSOFT1 + 数据/文本/概率 SHA256，拒绝缺失/错配标签。
- `campus.py` 添加三族拓扑留出、左右配对可见目标区、自有程序化贴图；teacher 按实际长方体尺寸避障。
- `collect/preprocess/eval` 贯通地图/外观/资源/目标判据等身份；审计新增校园专用实质检查。
- 保留旧 base/l1 字节与成功定义，入口文档集中指向 HANDOFF；实验设备层明确标记为未接入。

## 没做什么

- 未改 UI、ESP32、镜像、旧权重/旧软标签：超出主线范围，且需保留历史复现。
- 未删除设备层/BatchReader/镜像：它们有实验或归档用途，不是已证实无用代码。
- 未做长训练、正式多seed学生闭环或真机验证：本轮交付工程修复与可运行校园pilot，不据此报告性能提升。
- 未加入未标定的相机畸变/风/真机参数：方案中列为后续逐因素实验，目标实机数据尚未提供。
- 未更换引擎、下载第三方场景或采集照片：当前阶段使用可复现程序化资产。
- 未改 resume 的数据/RNG契约：该项在审计中提出，但没有纳入最终实施方案，仍是已知后续风险。
- 未提交/推送：用户没有要求 Git 写操作。
- 未改已有未跟踪的 `2026-11-03-sim-realism-implementation.md`：它在任务开始前已存在。

## 风险与遗留

- 仅三族拓扑，不代表充分泛化；仍是定高单帧策略。
- 地面圆盘并非在所有前视帧可见，可观测锚点是固定尺度的彩柱；几何可见性检查不能替代视觉学习验证。
- 旧软标签需重导出；历史碰撞漏报可能影响旧成绩，不能直接拿新旧成绩作模型改善结论。
