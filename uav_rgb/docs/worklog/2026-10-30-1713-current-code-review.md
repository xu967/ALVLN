## 应修复的测试和数值边界

### 4. [P2] 对拍误差函数会吞掉 NaN

- **位置/作用**：`src/tests/test_conv_cuda.cpp:41`、`test_linear_cuda.cpp:41`、`test_nn_cuda.cpp:26`、`test_weighted_loss.cpp:45` 用 `std::max(error, fabs(a-b))` 计算误差，是 CUDA/CPU 对拍的验收依据。
- **触发与结果**：主 agent 编译实测，有限参考值 0 与结果 NaN 比较，`std::max(0, fabs(0-NaN))` 返回 **0**；若其他元素相等，整张量仍显示零误差。
- **最小修复/回归**：有限对拍用例先检查形状和双方每个值的有限性，再计算误差；给比较函数喂“参考有限、结果含 NaN”的张量，断言失败。专门验证 NaN 传播的用例继续显式用 `isnan`，不把 NaN 当作数值相等。
- **不修影响**：resident/kernel 重写产生 NaN 时，部分对拍断言可能仍通过。**这不是当前已出现 NaN kernel 输出的证据。**

### 5. [P2] 有限的大类别权重使加权梯度归零

- **位置/作用**：`src/softmax_cuda.cu:253`、`src/ops_weighted.cpp:83` 将 double 的样本权重和窄化为 float；显式类别权重入口接受正有限值。
- **触发与结果**：`logits=zeros([2,4])`、labels `[0,1]`，四类权重全为 `3e38f`。CPU/CUDA 均返回正常 loss `1.38629`，梯度却全为 ±0；全 1 权重时应为 `[-.375,.125,.125,.125,.125,-.375,.125,.125]`。权重共同乘正常数本不应改变归一化后的损失和梯度。
- **最小修复/回归**：保留 double 归一化，或先稳定计算归一化后的权重比例再乘 softmax 梯度；补全体权重缩放不改变 loss/grad 的性质测试。CPU 与 CUDA 都要修，单纯 parity 抓不到两边相同的错误。
- **不修影响**：显式大权重的学习信号静默消失，现有有限 loss 检查不会报警；已有 Adam 动量仍可能更新参数，不能笼统说所有状态都不变。本轮未在正常 auto 权重范围复现该问题。

### 6. [P2] norm 转 float 溢出时裁剪静默清零

- **位置/作用**：`src/nn_cuda.cu:310、316`，CPU 对应 `src/nn_cpu.cpp:188、194`。平方和使用 double，但 sqrt 转 float 后没有再检查。
- **触发与结果**：有限梯度 `[3e38f,3e38f]`、`max_norm=5`。CPU/CUDA 均实测 `norm=inf coef=0 values=[0,0]`，正确裁剪结果应约为 `[3.5355,3.5355]`。
- **最小修复/回归**：用 double 完成 norm/系数计算，或在 norm 不能表示为有限 float 时明确抛错并保持梯度不变；不能成功返回零梯度。补“输入每项有限但整体 norm 超过 FLT_MAX”的用例。
- **不修影响**：极大但有限的梯度绕过非有限平方和检查，优化器收到错误的零梯度。此处为数值边界，未证明当前 T6 运行出现了这样的梯度。
