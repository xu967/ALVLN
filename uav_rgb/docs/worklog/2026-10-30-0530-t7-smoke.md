# T7 冒烟：新权重的闭环表现（3 集）

- 时间：2026-10-30 05:30
- 范围：`sim/tools/eval_closed_loop.py --policy student`
- 结论：**仍未通过**。3/3 撞柱、SR=0；但碰撞点从旧模型的 1.0–2.1 m 推到
  3.4–3.7 m，且 0 次 SAFE。离线指标与闭环严重脱节。

## 做了什么

- 用 T3 的 `ckpt_best.bin`（epoch 7）在 3 个 test 场景（seed 23/25/36）闭环飞，
  每集最多 80 步、`hold=1.0` sim-time：

```bash
DISPLAY=:20 XDG_RUNTIME_DIR=/tmp/xdg "$UAV_RGB_PYTHON" sim/tools/eval_closed_loop.py \
  --policy student --ckpt "$DATA_ROOT/uav_rgb/t2-v3c-044240/run/ckpt_best.bin" \
  --seeds 23,25,36 --steps 80 --hold 1.0 --split test \
  --out "$DATA_ROOT/uav_rgb/t7-smoke-051500"
```

- 注意 `--episodes` 默认 **3**：传 5 个 seed 也只飞 3 集，要全跑必须
  `--episodes 5`（本次只跑 3 集就停了）。

三集都在第 21–22 步撞柱；`false_forward_rate=1.0` 表示每一步「前进」都被地面真值
判定为不安全——模型不是偶尔撞，而是一路盲目前进直到撞上。

## 为什么离线 0.5859 的 macro_f1 没转化成闭环

1. **test 的 SAFE 被 safe 出生集放大到 42.9%**（120/280），模型只需在「整集悬停」
   的画面上输出 SAFE 就能拿满 SAFE 召回；正常飞行中它从没输出过 SAFE。
2. train 里 SAFE 只占 15.4%，且全部来自少数 safe 集；模型学到的是「近柱静止画面 →
   停」，没学到「飞行中前方被挡 → 停」。
3. 类别权重 auto 只平衡 loss，不改变「多数画面是空走廊 → 前进」的先验。
4. 闭环起点是 default(-0.5, 0)，与 safe 集分布不同；离线测试没有覆盖
   「普通飞行轨迹上的 SAFE 决策」。

## 没做什么

- **没有跑满 5 个 seed**（`--episodes` 默认 3，脚本提前停）；也没有跑 20 集。
- **没有跑盲前进/多数类先验的闭环基线**，无法给出相对提升。
- **没有调阈值/后处理**：例如对 FORWARD 加安全门限，这属于 T6/T7 的策略问题。
- **没有重新训练**：本轮只诊断，不改数据/超参。

## 风险与遗留

- 如果直接把「离线 macro_f1 0.5859」当成算法进展汇报，会严重高估——闭环仍是 0。
- T5 采集必须补「普通飞行中遇到障碍→SAFE/转向」的样本，而不是更多悬停集；
  否则 T6 训练完闭环大概率还是 0。
- safe 出生在 test 里的占比（3/7 集）让离线 SAFE 指标失真，后续报表要按
  spawn 模式分层报，或给 test 固定普通出生为主。
