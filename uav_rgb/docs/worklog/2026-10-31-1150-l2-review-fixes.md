## 做了什么

评审（`/ponytail:ponytail-review`）提了 1 个 must + 4 个 should + 3 个 nice，全部修了：

- **旧侧车不再拒绝整个数据集**（`dataset.cpp`）：`instructions.jsonl` 没有 `text_ids`
  时当作「没有侧车」直接返回，而不是 `fail`。修前实测：`l1-pilot-120-0642` 的数据集
  连 image-only 的 `--eval-only` 都跑不了（`UAVR: instructions.jsonl 缺 text_ids`，
  exit 1）；修后同一命令能走到 checkpoint 那一步。
- **超长 token 报错**（`dataset.cpp`）：`text_ids` 超过 `kTextLen` 由静默截断改成
  `fail`。`TEXT_LEN` 在 `preprocess.py` 和 `text.hpp` 各一份，漂了就会悄悄改掉指令。
- **`--text` 越界拦截**（`infer_main.cpp`）：上限从 255 收到 `kTextVocab`。之前
  id≥22 会被模型当 `<pad>` 静默忽略，词表一扩就静默退化成"无指令"。
- **`config.json` 记录 `text_dim`**（`class_weights.cpp`）：L2 的 A/B 两组同超参，
  没有这个字段无法从 run 目录判断哪个是文本模型。
- **`--exclude-safe-episodes` 负例**（`check.sh`）：把一集改成 `planner=plan_action`，
  断言打包后只剩一条指令行。这一支静默失效会让对照组和主组吃同一份数据。
- **`forward` 不再无条件复制 flat**（`model.cpp`）：image-only 路径每 batch 省一次
  约 10 MB 的深拷贝，`flat_ext` 只在 `text_dim > 0` 时构造。
- **`cnn_grad_tensors` 改用 `ndim() != 0` 判哨兵**（`model.cpp`）：原来写 `numel() > 1`，
  依赖"默认 Tensor 是 1 元素标量"这个隐含约定。
- **`infer.hpp` 过期注释**：删掉「L0 暂不参与前向」。
- 新增测试：`test_text_branch` 加旧侧车（不报错）+ 9 token（报错）两例；
  `test_trainer` 加 `config.json` 带 `text_dim` 的断言。
- 文档：`2026-10-31-l1-full-400-image-only.md §3` 用真实 `eval.json` 补全闭环结果
  （34 集逐集表 + 三条失败条件各自的通过数）；`l1-language-task-design.md §7.2`
  修正 test 集数（33/8 对 → 34/7 对，附修正说明，阈值不动）；§7.3 补
  `--exclude-safe-episodes` 的口径警告、D-STACK 状态改为已定；文本分支 worklog 里
  「没有重打包数据集」改为已完成。

## 没做什么

- **没有训练 L2 文本模型**：本轮只修代码。训练要等 `--text-mode` 消融开关落地
  （`S` 组需要 collect 侧覆盖指令）。
- **没有改 `--text ""` 的语义**：文本模型收到空指令仍然走全 pad（消融依赖它），
  这是有意的，不是漏判。
- **没有给 `parse_text` 加单测**：它在 `infer_main.cpp` 的匿名命名空间里，要测就得
  抽成库函数，为一个上界常量不值得。
- **没有重跑闭环**：本轮改动不影响 image-only 路径（`text_dim=0` 时行为等价，
  `flat_ext` 只少一次拷贝），没必要再烧 53 分钟。
- 没有提交、没有推送。

## 待确认
