# 场景外观 v1：删除固定地标 + 随机光照/天空（不动几何）

- 时间：2026-11-03 08:40
- 范围：`sim/tools/scene_gen.py`、`sim/tools/collect_parallel.py`、`sim/tools/eval_closed_loop.py`、`sim/tools/test_spawn.py`
- 结论：部分完成（方案 A 第 1 步完成并验证；第 2 步纹理、第 3 步渲染 pilot 未做）
- 依据：`docs/worklog/2026-11-03-sim-scene-realism-proposal.md` §4.2 第 1 步

## 做了什么

- `scene_gen.py` 新增 `--appearance legacy|v1`，默认 `legacy`；`build_scene()` 加同名关键字参数。
  - `legacy`：仍返回模板原文头部的字节，**输出与改动前逐字节一致**。
  - `v1`：删掉模板里 3 个固定纯色方块（`landmark_red/green/blue`，固定坐标、每集都在、
    不在 pillars/`geometry_gid`/教师真值里），并用 `<scene>` + 每 seed 的太阳方位/高度角/
    强度/色温/环境光/天空色替换原来固定方向光。参数由 `appearance_params(seed)` 生成，
  用独立 RNG 流（`seed ^ 0x4F0EA7`），不扰动 `sample_pillars`/`make_spawn` 的随机序列。
- `meta` 增加 `appearance_version`（两种外观都写）与 `appearance`（仅 v1，含光照参数），
  **不改** `geometry_version`/pillars/`geometry_gid`/`SPLIT_SALT`。
- `collect_parallel.py`、`eval_closed_loop.py` 新增 `--appearance` 并透传给 `scene_gen`
  子进程，采集/评测协议不变。
- `test_spawn.py` 增加回归：3 个 golden legacy sha256（改动前实测）+ v1 确定性、
  无固定地标、有 `<scene>`、柱子几何与出生位姿与 legacy 完全一致。

## 没做什么

- **没有加程序化纹理/PBR（方案 A 第 2 步）**。原因：需要先确认 llvmpipe 下纹理采样的
  真实渲染成本，而成本 pilot 必须独占 CPU 才准（见下条）；先交付「删捷径 + 光照」这一半。
- **没有跑渲染成本 pilot（第 3 步）**。原因：`student-a50/a80` 训练正在跑（预计 10:15 结束），
  软件 GL 渲染是 CPU 密集型，与训练并发会同时污染「wall/step」测量和训练耗时。
  等训练结束再跑 1 实例×10 步 + 4 实例×20 步的 legacy vs v1 对照。
- **没有跑配对闭环 A/B（第 4–5 步）**。原因：依赖 pilot 结果与 v1 采集数据。
- **没有改地面材质**（仍是纯灰、specular 0.8）。原因：属于第 2 步纹理范畴，需要贴图资产；
  单独改颜色只会把地板换成另一种纯色，对「纹理缺失」这条差距没有帮助。
- **没有改 `split_manifest.py` 记录外观版本**。原因：`geometry_gid` 只由 pillars 决定，
  外观不影响 split；是否在 manifest 里加字段等第 2 步纹理落地时一起定。
- **没有目视检查 v1 的实际渲染效果**。原因：同第 3 步，需独占渲染。

## 待确认

- v1 的太阳方向约定（`<direction>` 是光线传播方向，`-z` 向下）只按 SDF 语义写的，
  没有出图确认阴影落向是否符合预期；pilot 时第一张图就要看这个。
- v1 是否要保留 3 个地标的**碰撞体**但去掉可见性？目前是整块删除。它们 1 m 高、
  巡航高度 2.3 m，实测不挡飞行，删除不影响物理，但如果以后有低空任务要重新评估。

## 风险与遗留

- 外观改了但**几何仍只有 1 族**，任何结论都不能说成「泛化提升」。
- 旧 legacy 数据与 v1 数据**不能混在同一次训练**里（几何可互换、外观不可混）；
  `appearance_version` 已写进 scene meta，但打包/训练链路还没按它做拦截。
- golden sha256 写死在 `test_spawn.py` 里，以后有意改模板必须同步更新这三个值，
  否则测试会红——这是刻意留的门，不是误报。
