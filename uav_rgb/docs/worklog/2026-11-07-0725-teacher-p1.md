## 做了什么

### A. `teacher_kino.plan_costs`（代价单位：秒）

- `plan_costs(...) -> {action: cost_to_go}`，`plan_action = argmin_action(plan_costs)`。实现是**一次联合搜索**（`search_costs`）：四个首原语的子树共用一个堆和一张 `seen` 剪枝表，每个首原语的代价 = 它子树第一个终点弹出时的「f 层级」（已弹出 f 的运行最大值，pathmax 思路，用于启发不一致的情形）；被别的子树在同格剪掉的首原语记 Δg + 对方代价；预算用尽记 `max(best_f, f_level)`；四个全 inf → fail closed（SAFE）。
- 为什么不是四次独立搜索：门柱场景独立搜索丢了跨分支的同格剪枝，SAFE 19.3 < FORWARD 19.6，复现不出 v1 的 argmin。为什么不是终点 g：v1 的到达节点实际按 g+h 排序且启发不一致，用 g 一致率只有 92.6%。
- 步长/延迟/漂移做成 `Model(step_s, latency_s, drift_vx, drift_vy)` 参数；默认 NOMINAL 与原常量相同，旧调用逐位不变。3DGS 数据是 dispatch 语义（hold 0.5 s、无窗口内延迟）→ `Model(0.5, 0.0)`。
- 验证：`teacher_kino.py` 自检（新增 plan_costs 单位/排序/全 inf/门柱用例）、`test_teacher_kino.py` 全过；20 seed × 2 任务 ×（闭环轨迹 + 扰动状态）共 3200 个状态 v1 vs v2 `plan_action` 一致 3198（99.94%；闭环轨迹 1600/1600），2 个不一致都是四原语全 inf 的必撞扰动状态（v1 取启发最小节点的首原语，v2 SAFE）。耗时 8 → 25 ms/步（四棵子树都要搜到终点）。脚本与结果：`agent4-teacher-p1/compare_plan_action_v1_v2.{py,json}`。

### B. `sim/tools/teacher_belief.py`（纯 numpy）

- 可见集：60° 水平视场内 121 条射线、8 m、半格步进，`Scene2D` 二维占据（Gazebo 柱阵/森林由 `from_obstacles`，3DGS 由 `from_occ_npz` 读 `build_occ_cache.py` 落的碰撞代理 2D 占据）。自身 0.5 m 内视为已知空。
- K 个世界假设（默认 8）：已知世界（可见占据）+ 不可见区按场景先验采样（柱阵密度 / 森林层 / 3DGS 以 10 m 局部占据率采样 0.4 m 团块）；每个假设独立采样执行延迟（Gazebo [0.1, 0.2] s，3DGS [0, 0.1] s）与悬停漂移（≤ 0.03 m/s）→ `plan_costs`。假设间共享「已知世界」的 Dijkstra 启发（对所有假设都是下界，可采纳）；每个假设只重算净空表。
- 聚合：QMDP 平均（Littman 1995）或 CVaR_q；撞/停不住的动作记有限代价 C_COLL = 2×视野时长；p(a) ∝ exp(−Q̄/α)，α = `alpha_steps` × step_s（默认一步）；全部假设全部动作不可行 → `fail_closed` + SAFE 独热。
- 输出每步 `{p[4], q_bar[4], k_feasible, fail_closed, visible_frac}`；CLI 写 npz（`{eid}/{step}/logits` = log p）+ 统计 JSON，`join_soft_targets.py --temperature 1.0` 拼成 UAVSOFT1。
- 测试 `test_teacher_belief.py`（~14 s，全过）：(a) 全可见 K=1 argmax == `plan_action` 且 q_bar == `plan_costs`；(b) 「拐角后藏柱」：p(FORWARD) 0.723 → 0.549，SAFE+YAW 0.277 → 0.451，visible_frac 0.289；(c) 温度单调（α 0.5/1/2/4 熵 0.719 < 1.053 < 1.247 < 1.341，argmax 不变）；(d) 同 seed 逐位一致、不同 seed 不同；(e) 合成 3DGS 走廊（p 归一、argmax FORWARD；被八邻格围死 → fail_closed；停止半径内 → SAFE 独热）。

### C. DAgger 链路

- `collect_3dgs.py --policy student --ckpt C [--beta B] [--dagger-round k]`：`DaggerPolicy` 每步先让 `OccAstarTeacher` 标 `action_expert`，学生出 `action_executed`，以概率 β 改执行教师动作；manifest 加 `executed_by=student / dagger_round / beta / student_ckpt(_sha256) / n_expert_executed`；`teacher` 仍是 `plan_action`，preprocess 白名单不变。
- `preprocess.py`：读 `executed_by`（teacher|student）、`dagger_round`（≥0 整数）、`beta`（[0,1]），写进 UAVR meta 的 episodes 表（缺省 teacher/0/1.0），其它逻辑未动。
- `join_soft_targets.py`：支持没有 instructions 侧车的数据（flags=0，text_hash 全零），按 UAVR episodes 表的 `source_dir/sample_start/sample_count` 对齐；meta 多记 `teacher_version / belief_k / belief_alpha_steps / belief_aggregate / belief_seed`。`tools/test_join_soft_targets.py --native-check`（`test_soft_targets_identity`）通过。
- `tools/dagger_pipeline.py`：配置区 CFG；第 0 轮（pilot 或 `--collect-round0` astar 现采）→ 标注 → 打包 → 训练三臂（hard 类权重 / soft 软标签 / hard_plain 无类权重）→ 评测 6 路线 × 3 集；第 k 轮 soft 学生自采（β：0.5, 0）→ 并集重打包 → 训练 → 评测；`--dry-run` 打印全部命令；`--domain gazebo` 只打印 Gazebo 侧命令；同一 `--out` 可断点续跑。无 val split 时用末轮 `ckpt.bin`（trainer 只在有 val 时写 `ckpt_best.bin`）。

- Gazebo 侧只有命令（`collect_parallel` 还没有 `--policy student`；本机不跑 Gazebo）。
- `teacher_belief.py` CLI 只收 `--occ-npz`（3DGS）；Gazebo 柱阵/森林走库 API（`BeliefTeacher(scene, PRIOR_PILLARS/PRIOR_FOREST, MODEL_GAZEBO, boxes=..., discs=...)`），没有批量 CLI。
