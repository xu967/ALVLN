## 风险与遗留

- `_apply_render_backend` 写本进程 `os.environ`（与 `_set_partition` 同一做法）；Studio 进程内其他子进程都会继承。
- 手动评测现在可能弹两个确认框（协议推断失败 + Task 不一致），交互多了一步。
- 按机体高度投影后，机体离地很低（<0.3 m）时半径圈接近地面投影，与旧录像不可直接比对。
- `sdf_root` 去注释重试只处理注释里的 `--`；模板若有其他非良构 XML 仍会返回 None。
- check.sh 同时跑别的 agent 正在改的 `sim/tools/` 测试，本次全过；若之后他们继续改动而失败，不属本轮。
