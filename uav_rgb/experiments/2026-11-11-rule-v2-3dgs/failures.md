## 2. 事实

1. 主臂出生后没有碰撞。主臂的碰撞（holdout 2/96，formal40 3/120，室外 1/120）全部是出生即碰撞（`collision_step == 0`，出生扰动把飞机放进碰撞包络），出生后撞在前 0 集，到点之后的碰撞也是 0。v1 在 holdout 3 集、formal40 4 集有碰撞，各含 1 集出生之后的。出生即碰撞的集在各臂之间是同一批（`RESULT.md` 的出生即碰撞表），规则 v2 对这部分没有作用，K1 §18 的口径是只计数不处理。
2. 两步原地循环没有了。v1 的超时集（holdout 29，formal40 36）里 25 与 31 集归「末段不动」，超时集转向步占比 0.855 与 0.790，成功集是 0.568 与 0.540；`RESULT.md` 的分类里 v1 的「超时·含交替」是 holdout 26、formal40 32，两个 v2 臂都是 0。主臂超时集的转向步占比（0.420、0.461）与成功集（0.441、0.440）接近，没有多转。
3. 主臂剩下 20 个超时集（holdout 8，formal40 12）：目标点停滞 3，末段不动 7，仍在位移 10。20 集离终点最近时仍有 1.63 至 5.92 m（到点半径 1.0 m）。
4. 超时集与成功集相比：`V2-seek` 步占比 0.214 与 0.182（成功集 0.032 与 0.041，是成功集的 6.7 倍与 4.4 倍），`V2-fwd` 占比 0.590 与 0.564（成功集 0.738 与 0.721），`V2-stuck` 占比 0.009 与 0.022（成功集 0.003 与 0.005）。规则很少走到「所有候选都不通」的 `V2-stuck`，超时集里也只占 0.9% 与 2.2%。
5. 目标点停滞的 3 集（holdout `sage3d_841012` r8 seed 5801、formal40 `sage3d_839992` r19 seed 9901、formal40 `sage3d_841150` r4 seed 8402）：导引目标点在末段分别不变 64、37、58 步（前两集整集只变 0 次与 1 次），飞机到过离它 0.04、0.06、0.04 m 的位置。飞机贴着目标点时，目标点的方位随飞机的微小位移在 ±170° 附近翻，规则先转回去（`V2-back0` 连转 4 至 5 步）、前进 1 步，目标点又翻到身后（第 3 节第一段是 841150 r4，839992 r19 的第 13 至 25 步是同样的循环，见 `rule.jsonl`）。目标点跳变次数（相邻两步 `err_deg` 的绕圈差 > 100°）是 4、5、8，其余 22 个失败集 ≤ 2。这是 K1 §18 登记的「导引目标点不前进」；`RESULT.md` 按 K1 的判据（末 20 步目标点不变且末位姿离它 < 0.5 m）只把 841150 r4 一集计入，另两集的末位姿离目标点 0.76 m 与 2.16 m。本实验没有改导引，机制按 K1 的描述，没有再验证。
6. 其余 17 个超时集里，飞机在最后一段目标点不变的步里离该目标点最近仍有 1.19 至 3.21 m，没有追上目标点。其中 7 集末 30 步首尾位移不到 1 m（这 30 步的路径长度 2.60 至 6.71 m，在小范围内来回），10 集仍在位移，步数预算（`ceil(max_steps × 0.5) + 15`，封顶 100）用完。`V2-stuck` 收尾的失败集 0 个（`RESULT.md` 的 `V2-stuck` 收尾表，只有 1 个出生即碰撞集的第 1 步是 `V2-stuck`）。

## 4. 未核实

- 剩余超时集里候选航向之间的缝：`rule_v2_entry` 的 `shortcut:` 注释写的升级条件是「K3 的失败集里出现候选航向之间的缝里有路」。第 2 节第 4 条的数字只说明规则很少走到「所有候选都不通」（`V2-stuck` 在超时集里 0.9% 与 2.2%），`V2-seek` 占 18% 至 21% 的步；这些步里连续航向（不限于 α 的整数倍）能不能找到离导引更近的出口，没有重放记忆去查。要查的话：用 `rule.jsonl` 的 `d_occ` 与 `actions.jsonl` 的 `pose_gt` 逐步重放 `update_memory`，对 17 个非停滞超时集的 `V2-seek` 步做 1° 间隔的 `corridor_clear` 扫描。
- 导引折线在失败位置的栅格间隙（A* 路径本身是否贴着占据）：K1 同样标「未核实」，这里没有新数据。
- holdout `sage3d_841012` r27 四个臂都是 0/3 的原因：三集最近距离都是 4.03 至 4.04 m，飞机停在同一片区域；是路线几何、导引还是通道判定，没有查。
- 目标点停滞的机制：按 K1 §18 的描述，本实验没有改导引，也没有验证机制。
