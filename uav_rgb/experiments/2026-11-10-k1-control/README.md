# 2026-11-10 单块柱阵对照（长课程第 1 块为什么比单块柱阵低）

长课程第二轮（`experiments/2026-11-10-long-course/run_v2.sh`）里，学生在第 1 块的通过率是 39/60，同权重同 seed 的单块柱阵下午是 50/60。
第 1 块的几何与单块柱阵相同。下午之后入库了两处改动：新 E1 模板（保护罩外形，sha `2e554bcd`）与 A* 栅格缓存（提交 fcbf2fe）。
这个对照用长课程第二轮的同一份冻结代码重跑单块柱阵，分清原因在「代码与模板」还是在「课程本身」。

- 入口与预测：`run.sh` 文件头。一个臂：calswa 训练种子 1 加 `--heading-guard 2`，20 个冻结 seed，口径 `sim09.v2.coast1s.corridor3m`，1 条车道。
- 数据盘输出：`/root/rivermind-data/uav_rgb/exp-k1-control-20261110/`（`guard2-calswa-s1/eval.json`、`run.log`、`DONE`）。
- 对照臂：`/root/rivermind-data/uav_rgb/exp-heading-guard-20261110/guard2-calswa-s1/`（下午，旧模板 `21c8bc9a`，17/20）。
