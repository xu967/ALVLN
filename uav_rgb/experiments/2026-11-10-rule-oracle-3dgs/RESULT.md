# 3DGS 上的规则层上限（rule-oracle-3dgs）

- metric_version `3dgs.pilot.v2+stop.v1`；输出目录 `/root/rivermind-data/uav_rgb/exp-rule-oracle-3dgs-20261110/formal`。
- SR(stop) = 首次进入 waypoint 半径早于首次碰撞；碰撞率含到点之后的碰撞（与旧实验同口径，预注册的碰撞率用它），撞在前 = 没到点就撞；超时 = 既没到点也没撞；SPL(stop) 把成功换成 SR(stop)。
- 规则臂的列距离来自占据真值（occ）或渲染深度（depth），航向参照来自 oracle 路线或 waypoint 方位，都是特权信息：这是规则层的上限，不是学生能力。
