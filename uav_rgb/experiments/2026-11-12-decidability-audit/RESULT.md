# 可判定性审计（卡 E2E-0）：结果表

问题：特权 A* 教师在每一步给出的动作标签，能由哪些「端到端学生拿得到的信息」还原到什么程度。特征全部由仿真真值算，只用于分析，不进任何学生输入。

数据：5 个现成采集（trunc、more_demos、round_1、round_2、round_3），选步与 `tools/preprocess.py` 一致（`--drop-collision`），已与 5 份打包日志逐集、逐 split、逐类对账（§1）。
打包日志里的集数与样本数是累计数（round_k 的数据集含 trunc 与前几轮），去重后共 932 集、31,119 帧（来源：`features.npz`；各来源分摊：教师驱动 20,491 帧、学生驱动 10,628 帧）。
按 manifest 的几何分组切 train / val / test：786 / 66 / 80 集，几何簇（`geometry_gid`）462 / 39 / 40 个，共 541 个（来源：`recheck_tables.py` 的输出）。
每个特征组拟合 2×64 的 MLP，类别加权交叉熵，train 拟合、val 定停止轮数、test 报数，3 个种子。起跑前的预期与预注册读法写在 `run.sh` 头部，看到结果后没有改动。

数字出处：`$D/exp-decidability-audit-20261112/tables.md`（`audit_report.py` 生成，下文的 §n 指该文件的章节）与 `results.json`。提取、拟合、分箱由提交 `79a9f38` 的代码跑出（`inputs_run1.txt`），表由提交 `c9a1ef7` 的 `audit_report.py` 生成（`inputs.txt`）；
两个提交之间 `audit_features.py`、`audit_fit.py`、`run.sh` 的 sha256 相同，只有 `audit_report.py` 变了（补了主表与 pooled_u 的区间表，`results.json` 逐字节不变）。两份 inputs 还记了输入日志的 sha256。
本文的表原样摘自 `tables.md`，只把表里作占位的破折号换成「无」。单元格 `均值 [最小, 最大]` 的括号是 3 个种子的极差；
差值与判定的区间是按测试几何簇自助法 1000 次的 95% 区间（三个种子取均值，特征组之间配对）。

配置：主配置 `pooled_w` = 所有训练帧一起拟合、类别加权交叉熵，各子集只在测试帧上取数。卡没写拟合池与加权方式，另跑三个敏感性配置：
`pooled_u`（不加权）、`teacher_w`（只用教师驱动的训练帧拟合）、`student_w`（只用学生驱动的训练帧拟合）。结论依赖配置的地方在下文逐处标出。

子集（都在测试帧上取数）：教师驱动 = trunc 与 more_demos 的帧；学生驱动 = round_1、round_2、round_3 的帧（round_1 是 β=0.5 的混合执行，纯学生执行的 round_2、round_3 另列为 `student_r23`）；
画面空 = 60° 视场的 20 列距离全是 4 m 封顶，教师与学生的帧合在一起取。

指标：整体准确率为四类；macro-F1（F/L/R）为 FORWARD、LEFT、RIGHT 三类的宏平均（SAFE_NEUTRAL 在全部测试帧里只有 10 帧）；
「该转时转了」= 教师标签是 L 或 R 的帧里，被判成 L 或 R 的比例；「转向帧左右对」= 同一批帧里，L 与 R 两个 logit 比出的方向对的比例（不要求先判成转向）；
「前进帧被判成转向」= 教师标签是 FWD 的帧里被判成 L 或 R 的比例；基线 = 恒选 FORWARD_SLOW。

## 结论

学生驱动的帧上，只看当前画面的距离（S1）判不出转向的方向：转向帧里左右对的比例 0.508（95% 区间 [0.411, 0.601]），macro-F1（F/L/R）0.466；补上已执行的左转减右转次数 n（S3）后，左右对到 0.861（[0.768, 0.921]），macro-F1 到 0.711；只补上一步动作（S2）没有作用（左右对 0.526）。
再补 180° 宽视场与 hist（S5）macro-F1 到 0.781，再补特权量（S6）到 0.809，与带真实航向的天花板（S7，0.814）持平；S5 比 S4 高 0.089（[0.053, 0.134]），落在预期的「不到 5 个点」与「10 个点以上」之间，不能据此判定历史码够，也不能判定不够。
端到端学生的条件码应带 n 的计数（±4 共 9 档），不必带上一步动作，hist 在学生帧上没有增益（S4 比 S3 的 macro-F1 低 0.019，[−0.042, +0.010]）；W1-9 的三值航向码补上其中大部分（左右对 0.803，macro-F1 0.702），比 n 的左右对低 0.057（[−0.104, −0.017]），macro-F1 低 0.009（[−0.045, +0.019]，不加权时低 0.027）。

## 6. 分箱核对（不依赖拟合器）

分箱的定义见 `README.md`。注意：分箱里的 n 是三值航向码（|n| ≤ 1、n ≥ 2、n ≤ −2），所以分箱的 S3 对应 MLP 的 S3c，不对应 S3。
「箱内多数占比」是训练帧上每个箱里教师动作的多数占比，箱多帧少时偏高；「分箱留出准确率」是用训练帧的箱内多数类判测试帧（没见过的箱退回训练集的多数类），箱多帧少时偏低；
MLP 准确率应落在两者之间或与留出准确率同量级。分箱规则是不加权的多数规则，量级对照用「MLP 准确率（不加权）」一列。

## 7. 读法与限制

- 同分布：训练、验证、测试按几何分组切开，排除了同一几何的泄漏，所有几何来自同一个生成器；换布局族的泛化没有测。测试几何簇在教师驱动子集 36 个、学生驱动子集 19 个、画面空子集 39 个（§1），区间宽（学生帧上 S3 的左右正确率区间 [0.768, 0.921]）。
- 特征是无噪声的真值：`d` 与 `d_wide` 是理想的列距离，视觉前端读出来只会更差，所以这些可判定率是上界。`d_wide` 在这里代表「完美的短期记忆」，学生没有 180° 的相机。
- 「不可判定」在这里指「这组特征加这个拟合器还原不出的部分」，包括特征缺信息、教师在近平局帧上的 tiebreak 跳变、MLP 拟合不到的结构三种来源，本表不拆。S6 与 S7 的 macro-F1（0.809、0.814）是这套特征与这个拟合器的上限，剩下部分的来源未核实。
- 学生驱动的帧里，|n| ≥ 2 的帧占 19.6%，教师驱动的帧占 3.5%（`recheck_tables.py` 的输出）；在全部 split 的转向帧里，|n| ≥ 2 的转向帧占比：学生驱动 0.473、教师驱动 0.115，这些帧里标签朝回转的比例分别是 0.916（1592/1738）与 0.865（289/334）（`mech_check.py` 的输出）。
  学生驱动的状态里近一半的转向标签是回正，方向由已偏的方向决定，单帧距离里没有这个信息。
  分层核对（测试帧、pooled_w、3 个种子均值、只看判成转向的转向帧、方向对的比例；没做区间，样本小）：学生驱动的帧里 |n| ≥ 2 的 213 帧，S1 为 0.368，S3 为 0.890，S5 为 0.926；|n| < 2 的 155 帧，S1 为 0.661，S3 为 0.847，S5 为 0.879。
  S1 在回正帧上判成转向后的方向对低于 0.5，在 |n| < 2 的帧上为 0.66。教师驱动的测试帧里 |n| ≥ 2 的转向帧只有 28 帧（转向帧共 254 帧），分层的方向对 S1 为 0.588（28 帧）与 0.740（226 帧）。
  这个口径（判成转向后的方向对）与表里的「转向帧左右对」（用 L、R 两个 logit 比）不同，两者不能直接相加或相比，这里只用来看 |n| 分层后的方向。
- 区间是逐格的 95% 区间，没有做多重比较校正；读的时候看方向与量级，不看单个阈值的穿越。
- 三个种子的极差反映初始化与小批次顺序，不含训练几何的抽样波动。
